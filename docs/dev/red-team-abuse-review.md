# Red-Team Abuse-Lens Review

Review date: 2026-10-02
Scope: local source and behavior evidence in the current `slskR` worktree. This is a classified attacker-hypothesis review, not a penetration test or a claim about hosted or deployed systems. Raw grep totals are intentionally omitted because they are not exploit counts.

The registered scan registry calls for an attacker-view review, but the generated active-bughunt report did not have a red-team section. This register fills that gap by grouping the threat paths, recording the concrete guard and regression evidence, and reopening a row whenever its source boundary changes without matching evidence.

| Abuse class and hypothesis | Classification | Evidence reviewed | Confidence | Reopen when |
| --- | --- | --- | --- | --- |
| Identity spoofing and privilege escalation: caller-controlled identity, auth scheme, role, or route shape crosses an authorization boundary. | Existing Guard | `controller_route_auth_policy`; `check_route_auth`; `controller_auth_enforces_native_roles_schemes_scopes_and_anonymous_routes`; peer-session identity binding and `source_provider_host_matching_rejects_suffix_spoofing`; auth-profile differential gate. | High | A new route or identity source bypasses the policy registry or lacks a spoofing regression. |
| Confused deputy and delegated capability use: a share, peer, mesh, or pod capability authorizes a different grant, resource, or operation than intended. | Existing Guard | Versioned share-stream and backfill handlers validate the token's grant and permissions; pod sender identity and membership checks have impersonation regressions; `full_media_differential_fixtures` covers share-ticket rejection, grant permission, expiry/capacity, and restart behavior. | High | A new delegated route accepts a token without binding it to the target grant/resource and operation. |
| CSRF and replay: browser cookies authorize cross-origin mutations or a one-time nonce/state is accepted twice. | Existing Guard | `csrf_origin_allowed`; cookie-auth route tests; `spotify_oauth_callback_requires_server_issued_state`; `pod_join_enforce_mode_verifies_ed25519_and_rejects_replay`; `consume_oauth_state` removes and persists consumed state. | High | A new cookie-authenticated mutation or one-time action is added without origin/replay coverage. |
| Secret disclosure: credentials or private endpoints escape through diagnostics, logs, errors, or serialized configuration. | Existing Guard | Sanitized configuration and integration projection regressions, including `spotify_diagnostic_projections_redact_redirect_uri`, `lidarr_projections_redact_endpoint_and_errors`, and transfer/share error-redaction tests; secret-scanning and runtime-boundary gates. | Moderate | A new diagnostic/export/log path serializes configuration, headers, tokens, or filesystem paths. |
| SSRF, redirect, and DNS-rebinding abuse: a configured or caller-supplied target reaches a special-use address, follows an unchecked redirect, or resolves to a different address after validation. | Existing Guard | `integration_ssrf_filter_blocks_special_use_ip_ranges`; webhook/Lidarr target resolution and pinned-address clients; redirects and ambient proxies are disabled on reviewed outbound clients; webhook outbound-policy and proxy-policy gates. | High | A new outbound client uses an unpinned user-controlled host, ambient proxy, redirect, or unbounded response. |
| Filesystem/path escape: an indexed share path changes after lookup and opens a symlink or reparse point outside the configured share roots. | Fixed — BUG-097 | `validate_shared_local_file_path`; Unix descriptor-relative no-follow opens; `opening_a_previously_valid_share_rejects_a_swapped_outside_symlink`; `shared_file_open_rejects_paths_outside_configured_roots`; runtime-boundary hardening gate. Static replacement and root-containment cases are covered; a concurrent same-user filesystem race on non-Unix is outside the focused regression. | Moderate | Any file is opened from a share index, persisted path, or caller path without open-time root validation and platform-appropriate no-follow behavior. |
| Process/config injection: hostile request data becomes an executable, shell fragment, or argument to an operator-configured process. | Existing Guard | Script commands and executable paths originate in operator configuration; event payload is passed as `SLSKD_SCRIPT_DATA`, not appended to command text; Native command-mode rejects shell metacharacters (`native_command_safeguard_preserves_the_frozen_target_difference`); external visualizer launch is disabled by default and has an explicit-enable regression. The compatibility profile intentionally retains its configured shell semantics. | Moderate | Any remotely supplied value is concatenated into a command string, changes executable selection, or reaches a launch route without authorization and an explicit enable policy. |
| Resource exhaustion and operational downgrade: untrusted work bypasses request, response, connection, task, or timeout limits, or a deployment silently disables a security control. | Existing Guard | Request/body, frame, WebSocket, worker, and integration limits are covered by the runtime-boundary gate; API auth-disabled posture, CSP, WebSocket auth, Kubernetes public posture, and workflow policy have dedicated checks. This is source/gate evidence, not a live load or deployment exercise. | Moderate | A new unbounded queue/task, missing deadline, weakened public binding/auth default, or failure-suppression exception appears. |
| Browser injection and token theft: remote text reaches an HTML/code execution sink or API credentials persist beyond the intended session. | Existing Guard | `scripts/check-browser-injection-sinks.sh`; `scripts/check-browser-token-persistence.sh`; Web and SDK session-storage regressions; unsafe blank-open gate. | High | A new browser sink, persistent API-token write, or opener path lacks a behavior test and gate. |

## Closure boundary

BUG-097 is fixed with local regression coverage. The other rows classify the listed source and behavior paths against existing guards; they do not certify every route, every operating system race, hosted CI, production deployment, or external service. Fresh findings reopen their class and require a ledger row, behavior regression, sibling review, and a durable gate before closure.
